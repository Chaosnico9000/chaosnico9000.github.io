02 · About

About me

I'm a software engineer at LIST AG, based in Germany. I started out with small .NET / C# command-line tools and today work mostly full-stack in TypeScript on Bun: Next.js frontends, Hono APIs, a shared design system and the tooling that keeps it all consistent.

On the side I like going one level deeper, whether that's training a language model from scratch or reimplementing a game server in Rust. I like software that's lightweight, well tested, and does exactly what it promises.
